## 3. 進め方の目安

1. 毎日：順位1〜6から1テーマ、過去問の該当欄を時間を計って解き、同型のワークブック問題で解き方を確認。
2. 公式は Anki で暗記（`problems/anki/` のカード分類を参照）。
3. 週末：最新年度から1年分を通しで（2025→2024→…）。
4. 日本年金数理人会の問題は参考扱い。比較メモ：`docs/JSCPA比較.md`。
