# 日本年金数理人会（JSCPA）「年金数理」とアクチュアリー試験（IAJ）の比較

作成日：2026-11-08　／　対象：JSCPA 2015〜2025年度、IAJ 2016〜2025年度

このメモは参考資料です。JSCPA の問題文はそれぞれのPDFで確認してください。ここに書いたテーマは自分の言葉での要約です。
テーマが近いかどうかは、IAJ の各解答欄の要約（アプリの `problems/iaj-*.json`）と見比べて判断したもので、公式の対応表ではありません。

## 1. 出題時期に使える規則性はあるか

**結論：予測に使える規則性はありません。**

| 出題の順序（同じテーマが両方に出た場合） | 件数 |
|---|---|
| JSCPA（10月）→ 翌年〜2年後に IAJ（12月） | 11 |
| IAJ（12月）→ 10か月〜2年後に JSCPA（10月） | 7 |
| 同じ年（JSCPA 10月と IAJ 12月） | 15 |

- 最も多いのは「同じ年」です。IAJ の問題は試験よりかなり前に作られるので、因果関係ではなく、両試験が同じ定番テーマ（分割・統合、定年延長、連続モデル、1年間の推移の分析など）から出していると見るのが自然です。
- 目立つ点として、**JSCPA 2024年10月のテーマ4つが IAJ 2025年12月に出ています**（共同制度の分割、加入年齢方式と開放基金方式の比較、「給与×加入年数」の一時金、利回りが予定と違った後の給付調整）。1年分だけの観察で、規則とは言えません。
- IAJ の中では、**制度の分割が2017・2019・2021・2023・2025年度（奇数年）**、統合が2016・2020・2022・2025年度に出ています。5回分の観察にすぎず、2026年度の出題を予測する根拠にはなりません。

主な例：

| テーマ | 出題の流れ |
|---|---|
| 制度分割 | JSCPA 2016 → IAJ 2017。2021は同年。JSCPA 2024 → IAJ 2025。2025は同年 |
| 制度合併・統合 | 2016・2020・2022は同年。IAJ 2025 は JSCPA になし |
| 開放基金方式の保険料＝単位積立方式の保険料の加重平均 | JSCPA 2015・2016 → IAJ 2017 → JSCPA 2019 → IAJ 2024 → JSCPA 2025 |
| 複数の年齢での新規加入と後発過去勤務債務 | JSCPA 2019・2022 → IAJ 2023 → IAJ 2025 |
| ベースアップ後に保険料を据え置いた場合の積立金 | JSCPA 2022 → IAJ 2023。2023は同年 |
| 1年間の責任準備金・積立金の推移と分析表 | JSCPA 2022 → 2025は同年（JSCPA 問18 と IAJ 問題3(3)） |
| 定年延長 | IAJ 2018 → JSCPA 2020〜2022 → 2022・2024は同年 → JSCPA 2025 |
| 動態的昇給率 | IAJ 2021 → JSCPA 2023 → 2025は同年 |

## 2. JSCPA 2024〜2025年度に出て、IAJ 2016〜2025年度にまだ出ていないテーマ（練習候補）

- **据置期間中の遺族年金付きの年金現価**（2025問4。JSCPA では2019問4・2022問3にも出題）
- **弾力償却**（2025問6。JSCPA では2022問10・2023問11にも出題）
- **給与改定後の極限方程式**（2025問8。2020問6も同系）
- **貸借対照表・損益計算書にベースアップ要因を加えた未積立債務の変動分析**（2025問12。2022問12も同系）
- 2つの脱退残存の形による保険料率の大小（2025問20。2022問20も同系）
- 2制度の比較から予定利率を求める（2025問10）
- 到達年齢方式で責任準備金が基準を超える年度（2024問9）
- 給付改善できる回数の最大値（2024問12。IAJ 2017年度 問題1(5) と一部似ている）
- 脱退率のスムージングと保険料（2024問19）
- 2国間の移住が続いた後の新しい定常人口（2024問2）、死力一定の3人連生の連続年金（2025問3）

## 3. IAJ 対策として勧める JSCPA の問題

## 4. 注意点

- **形式が違います。** JSCPA は2019年度以降、問1〜15が選択式、問16〜20が記述式（証明や計算過程を含む）です。IAJ は選択と数字の穴埋めが中心なので、JSCPA の証明問題は考え方の確認用にしてください。
- **出題範囲が少しずれます。** JSCPA は実務寄りのテーマ（弾力償却、想定選択率、ポイント制、実務型の財政計算）が多めです。
- **不備・訂正の告知があります。** 2013年度 問2（全員正解扱い）、2018年度 問18（全員正解扱いを含む）、2019年度 問3（得点調整なし）。告知のPDFは同じフォルダにあります。
- 2018年度の問題PDFは文字の抽出がうまくいかなかったため、この年度のテーマ（特に問1〜8）は大まかな推定です。
- JSCPA は自分の過去問に近い問題を繰り返すことがあります（2017問19と2025問19、2019問4と2025問4、2021問15と2022問15）。
